# Travaux Pratiques en Modélisation Économétrique

Ce dossier contient les travaux pratiques (TP3) du cours d'Économétrie (ECO2547) pour la session d'Hiver 2024. Le projet se concentre sur l'application de méthodes économétriques pour l'analyse de données financières.

## Objectifs du Projet

*   **Application de Modèles de Régression** : Mettre en œuvre des modèles de régression linéaire multiple pour l'analyse de données.
*   **Interprétation Statistique** : Interpréter les coefficients des modèles et les résultats des tests statistiques.
*   **Validation des Hypothèses** : Analyser et valider les hypothèses fondamentales des modèles économétriques.

## Contenu du Répertoire

*   `Analyse_Econometrique_ECO2547_TP3.xlsx` : Le fichier Excel contenant les données et les analyses préliminaires des travaux pratiques.

## Outils Utilisés

*   **Logiciel** : Microsoft Excel
*   **Fonctionnalités** : Outils d'analyse de données, fonctions statistiques.
